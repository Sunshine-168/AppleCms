## 📖 一、项目介绍

EnovelCms 是一套原生 PHP 小说建站管理系统，基于 **PHP8.0 + MySQL5.7** 开发，无复杂前端框架，占用服务器资源极低。内置完整前台阅读、多端后台、全自动采集、会员充值、签到、自定义榜单、多语言、广告管理全套功能，适合快速搭建网文阅读站点。

🌐 **官方网站**：[https://www.enovelcms.cn/](https://www.enovelcms.cn/)

---

## 🛠️ 二、环境要求

| 环境 | 版本要求 |
|------|----------|
| PHP | ≥ 8.0（需开启：cURL、mbstring、fileinfo、zip） |
| MySQL / MariaDB | ≥ 5.7 |
| Web 服务器 | Apache / Nginx / IIS |
| 目录权限 | `data/`、`assets/uploads/` 需可读写（755/777） |

---

## 🚀 三、安装步骤

1. 将源码完整上传至网站根目录；
2. 复制 `includes/config.example.php`，重命名为 `includes/config.php`，填入数据库地址、账号、密码；
3. 给 `data/`、`assets/uploads/` 目录设置 755/777 读写权限；
4. 浏览器访问 `域名/install/install.php`，跟随安装向导完成数据库导入；
5. 安装完成后建议删除 `install` 文件夹，提升站点安全；
6. 后台访问地址：`域名/admin/`，使用安装时设置账号密码登录。

## 🛠️ 五、后台功能清单

### 🖥️ 基础控制台
展示小说、用户、章节、榜单统计数据；显示站点总阅读、收藏、今日签到数据；版本更新检测、管理员密码修改、官方公告。

### ⚙️ 系统设置
网站基础信息、Logo上传、分页配置、统计代码；签到金币、连续奖励配置；VIP月充值价格；SMTP邮件发件配置；注册登录模式切换。

### 🎨 主题管理
模板上传、安装、删除、切换；读取模板内 `template.xml` 信息，支持主题预览图展示。

### 📖 小说管理
新增/编辑/删除小说；封面上传预览；批量同步全站小说总字数；分卷、章节快速跳转；分页展示小说列表。

### 🤖 采集模块
1. **采集规则**：新增、编辑、导入导出JSON规则、在线测试、单篇/批量采集；
2. **采集配置**：自定义API密钥、源站分类映射、第三方采集接口文档；
3. **批量采集**：支持单ID、区间ID（1-100）、逗号多ID批量抓取；
4. **采集逻辑**：自动分页列表、分卷识别、章节分页合并、封面自动下载、内容过滤。

### 🏷️ 分类管理
小说分类新增、编辑、排序、删除。

### 📑 分卷管理
按小说创建/修改/删除分卷，删除前校验是否存在章节，配套分页展示。

### 📄 章节管理
按分卷分组展示章节，分页加载；单章新增、编辑、删除；支持AJAX读取章节正文，自动统计章节字数。

### 👥 用户管理
全站用户列表，可跳转编辑用户金币、VIP到期时间。

### 📋 签到日志
按用户名、日期筛选签到记录，展示当日签到金币发放明细。

### 📢 广告管理
全站多页面广告位HTML投放；章节内容关键词自动内链替换。

### 📊 自定义榜单DIY
自定义榜单筛选条件：分类、字数、更新/点击/收藏排序、缓存时长；支持自定义小说列表榜单。

### 🔍 SEO设置
首页、书库、阅读页等多页面标题/关键词/描述模板，内置站点、小说、章节动态变量。

### 💳 支付配置
对接易支付，配置商户ID、密钥；自动处理VIP充值时长叠加。

### 📦 充值订单
VIP充值订单筛选、分页，展示支付状态、金额、创建/支付时间。

### 🌍 语言管理
多语言包上传、切换默认语言，支持中英双语。

### 🔗 伪静态规则
自动识别Nginx/Apache/IIS服务器，输出对应Rewrite配置。

## 🔒 八、安全建议

1. 安装结束删除 `install` 安装目录；
2. 定期修改后台管理员密码，开启图形验证码登录；
3. 采集API密钥设置复杂字符串，禁止对外泄露；
4. 限制 `data/` 目录外网直接访问；
5. 定期备份数据库与封面、模板文件；
6. 伪静态关闭目录浏览权限。

---

## 🔄 九、系统升级流程

1. 升级前备份数据库、`templates` 自定义模板、`assets/uploads` 上传图片；
2. 下载新版源码，覆盖除 `includes/config.php`、自定义模板、上传目录以外文件；
3. 访问后台，系统自动执行新增数据库字段升级，无需手动执行SQL。
